# Reference Source Model (Phase 4B)

`CbamReferenceSource` stores **metadata only**:

- code / name / source_type
- publisher / version_label / publication_year
- optional URL / description

Platform seeds (org null): IPCC, DEFRA, EPA, PRIMARY_MEASUREMENT, SUPPLIER, MANUAL_APPROVED_REFERENCE.

No automatic web fetch, scrape, or public API import.
