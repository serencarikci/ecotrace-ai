# Glossary (CBAM / SKDM)

Short names used in this guide. UI labels stay exactly as shown in the app.

| Term | Meaning |
|------|---------|
| **Carbon Border Adjustment Mechanism (CBAM), called SKDM in Turkish** | EU border carbon reporting framework. In EcoTrace the module menu often shows **SKDM**. |
| **SKDM** | Turkish short name for CBAM. Use this when matching on-screen menu labels. |
| **CBAM SEE** | Official communications workbook for product embedded emissions (template family used by Official Excel). |
| **Official Excel** | EcoTrace screen and export that fills **CBAM SEE** from validated period results, recalculates formulas, then allows download. After this definition, prefer **Official Excel** in user steps. |
| **Internal Excel** | Separate internal workbook export (not the official CBAM SEE file). |
| **Product Results** | Screen that calculates product embedded emissions for the period. |
| **Direct / Indirect Emissions** | Screens for fuel (stationary combustion) and purchased electricity results used before allocation. |
| **Allocation** | Screens that split direct and indirect totals onto products. |
| **CN code** | Customs / Combined Nomenclature product code used on profiles and precursors. |
| **Out of date** | Saved results no longer match current source data; update/recalculate when the app allows it. |
| **Unbalanced** | Process or precursor quantities do not add up to zero remaining; fix quantities before readiness can pass. |

## Naming rule for this guide

1. First mention in a chapter: expand **CBAM** as above when introducing the topic.  
2. Define **CBAM SEE** once when talking about the official workbook.  
3. In user steps, use **Official Excel** for the EcoTrace action/screen.  
4. Keep exact UI strings unchanged (for example **Report / Excel**, **Download**, **Update product results**).
