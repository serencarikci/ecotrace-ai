# Reporting Limitations (Phase 6)

## Implemented

- Internal development XLSX via openpyxl
- Allow-listed mappings + repeating rows
- Formula preservation checks
- SKDM Dönem Özeti (JSON/HTML) — internal only
- Export readiness checklist
- Manifest + artifact checksums
- Tenant-isolated downloads

## Not implemented / BLOCKED

- Official EU CBAM / SKDM workbook format and cell mappings
- Official regulatory submission
- CN / AGC mapping
- Shipment information
- Evidence upload
- Certificate liability / financial CBAM obligation
- Sector-specific emission formulas in export
- Automatic IPCC/DEFRA/EPA download
- PDF generation (unless already elsewhere in the product)
- Macro-enabled workbooks (`.xlsm` rejected)
- LibreOffice automation
- Using Excel as a second calculation engine

## Explicit non-claims

Exports must not be labeled “Resmi CBAM Gönder” unless an official submission format is confirmed and delivered.
