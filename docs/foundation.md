# Foundation

Identity, organizations, security baseline, and platform delivery foundations for EcoTrace AI.

## Delivered

- Modular monorepo (`apps/api`, `apps/web`)
- FastAPI + Angular + PostgreSQL + Alembic
- JWT access tokens and rotating hashed refresh tokens
- Roles and organization memberships
- Audit logging, Docker Compose, CI

## Next building blocks

Operations, activity data, and carbon accounting build on this foundation.

See [operations.md](operations.md) and [carbon-accounting.md](carbon-accounting.md).
