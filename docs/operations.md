# Organization Operations and Activity Data

Organization-scoped operational sustainability data management for EcoTrace AI.

## Delivered

- Facilities, production lines, equipment, data sources
- Units and activity types (global reference data)
- Reporting periods with lock/unlock
- Activity records with workflow, revisions, optimistic concurrency
- Attachments and CSV activity imports
- Alembic migration revision `0002_phase2`

Unauthorized cross-organization access returns **404** (resource existence is not revealed).

See [carbon-accounting.md](carbon-accounting.md) for emission calculation on top of this activity data.
